# 📚 Library Management System

A Python-based Library Management System for managing books, members, and borrowing operations. This project is developed as part of the Software Quality Engineering Lab.

## ✨ Features

- **Book Management**: Add, remove, and search books
- **Member Management**: Register and manage library members
- **Borrow Operations**: Borrow and return books
- **Search Functionality**: Search books by title, author, or ISBN
- **Validation**: ISBN validation, duplicate checks, borrowing limits
